# Konsol (DD-140, DD-148): tek adres. /api/wg/* ve /api/konsol/* root arka uca (WireGuard,
# sistem, modüller), öbür /api/* dosya arka ucuna gider. Sayfaları Caddy doğrudan sunar:
# dosya yöneticisi bir modüldür ve kaldırılabilir, Konsol'un kendisi kalmalıdır. Yalnız
# tailnet'ten; CSRF ve Host denetimi arka uçlarda (DD-147), başlıklar burada.
http://panel.ayc {
	@kok path /api/wg/* /api/konsol/*
	handle @kok {
		reverse_proxy 127.0.0.1:61008
	}
	handle /api/* {
		reverse_proxy 127.0.0.1:61009
	}
	handle {
		root * /usr/local/share/master-stack/konsol
		header {
			Content-Security-Policy "default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' blob:; connect-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'"
			Cache-Control "no-store"
			X-Content-Type-Options "nosniff"
			X-Frame-Options "DENY"
			Referrer-Policy "no-referrer"
		}
		file_server
	}
}
# Modüllerin siteleri (DD-149): master-modul buraya <id>.caddy koyar ve kaldırır (ör. Paylaşım:
# paylas. adı ve Infuse için Tailscale IP:port). Eşleşmeyen kalıp geçerlidir; nokta ile başlayan
# geçici dosyalar okunmaz. Genel seçenek bloğundan sonra gelmeli.
import /etc/caddy/moduller/*.caddy
#==moduller/paylasim.caddy
# Modül: Paylaşım (DD-149). master-modul bunu CADDY_MODULES_DIR/paylasim.caddy olarak koyar;
# temel Caddyfile o dizini içe aktarır. Konsol'dan paylaşılanlar; salt okunur, tek hesap.
# İkinci adres Infuse içindir (DD-98): ad çözemeyen istemciler Tailscale IP:port ile bağlanır.
# Port yazılı gelir; {$TAILSCALE_IPV4} ortam değişkeni kalır (refresh-tailnet-config onu günceller).
http://paylas.ayc, http://{$TAILSCALE_IPV4}:61010 {
	reverse_proxy 127.0.0.1:61010
}
#==moduller/torrent.caddy
# Modül: qBittorrent (DD-151). master-modul bunu CADDY_MODULES_DIR/torrent.caddy olarak koyar.
# Arayüz yalnız 127.0.0.1'de dinler; tailnet'e bu ad açar.
http://torrent.ayc {
	reverse_proxy 127.0.0.1:61006
}
#==Caddyfile.wg
# WireGuard istemcileri için arayüz (DD-120): yalnız WireGuard sunucu adresinde,
# IP:port ile — ad yok, WebDAV yok. Tailscale'e bağlı değildir; tailnet Caddy'si
# (Caddyfile) ayrı süreçtir, biri düşünce öteki ayakta kalır. DD-151: yalnız qBittorrent
# modülünün arayüzü (modül kurulu değilse 502).
{
	admin off
	persist_config off
	auto_https off
	default_bind {$WG_BIND}
}
http://:61006 {
	reverse_proxy 127.0.0.1:61006
}
Caddy yalnız Tailscale adresinde (80, 61010) ve WireGuard adresinde dinler; HTTPS yok, tailnet zaten şifreli.

Neden salt okunur?

Bu sayfa değer yazmaz. Her ayarın tek bir sahibi vardır: kurulum (kurulum.env ve varsayılanlar), ilgili modül ya da qBittorrent'in kendisi. Konsol'dan değiştirmek ikinci bir doğru kaynağı açar ve yeniden kurulumda geri döner. Her satır, değerin nereden değiştiğini söyler.
